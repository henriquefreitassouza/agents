Creating a new post is intentionally lightweight:

1. Add a new `.md` file in `src/posts`.
2. Fill out the frontmatter fields (`title`, `description`, `date`, and optional `tags`).
3. Write markdown content below the `---` block.

Once the file exists, it automatically appears in `/blog` and is available at `/blog/<your-file-name>`.
