This post confirms the content architecture is working.

Each markdown file inside `src/posts` acts as a source of truth for one post:

- Frontmatter powers metadata for indexes and SEO.
- Markdown body is rendered on the dynamic post page.
- The filename becomes the post slug used in URLs.
